  usados para capturar son sintéticos.

## Regla para el estado “en producción”

Solo OMSTA se publica hoy con ese estado. Los otros proyectos están etiquetados
como “listos para producción” hasta que exista una URL pública verificable y pase
una comprobación de humo sobre esa URL. Al desplegar cada uno se añadirá el enlace
de demo y se actualizará `content/projects.data.ts`; no se anticipa el estado por
intención futura.
