## Necesidad

Una red social pequeña sigue siendo un sistema de relaciones: el contenido depende
de a quién sigues, cada interacción cambia varias vistas y las notificaciones deben
mantener contexto. El objetivo fue construir ese núcleo completo, no una maqueta de
un feed.

## Mi función

Diseñé la experiencia e implementé frontend y backend. El alcance incluye
autenticación JWT, perfiles, relaciones de seguimiento, publicaciones con imagen,
likes, comentarios anidados, búsqueda, temas y notificaciones.

## Decisión relevante

El feed usa paginación por cursor para sostener un orden estable mientras aparecen
nuevas publicaciones. Las notificaciones viven en un módulo separado, con sus
propias reglas y endpoints, en vez de quedar acopladas a las vistas de posts.

## Estado actual

Las 32 pruebas de backend pasan y el frontend supera lint y build. Las cuentas y
publicaciones de las capturas son datos sintéticos de demostración; no se usan como
métricas ni testimonios. La demo pública se enlazará después del despliegue.
