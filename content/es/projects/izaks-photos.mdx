## Necesidad

El proyecto debía hacer dos trabajos a la vez: presentar una selección amplia de
fotografías sin convertirla en una cuadrícula genérica y ofrecer un camino directo
para solicitar una sesión. La identidad visual tenía que sentirse editorial,
sobria y suficientemente flexible para retratos, bodas, viajes y trabajo de marca.

## Mi función

Me encargué de traducir esas necesidades en arquitectura de información, UX/UI y
desarrollo full-stack. Construí las rutas de inicio, galería, perfil y reserva; el
frontend responsive; y la integración del formulario con Django REST Framework.

## Decisión relevante

La fotografía no funciona como decoración, sino como la estructura visual del
producto. Reservé dimensiones para las imágenes, preparé recursos optimizados y
usé una galería con filtros y lightbox para que cada serie pueda explorarse sin
perder contexto. Para simplificar la operación, el despliegue previsto usa un solo
servicio de Railway: Django sirve tanto la API como el build de Vite.

## Estado actual

La versión limpia del repositorio pasa las cuatro pruebas del backend y compila el
frontend de producción. La URL pública se añadirá cuando termine el despliegue;
hasta entonces no se presenta una demo inexistente.
